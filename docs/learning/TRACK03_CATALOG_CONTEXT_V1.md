## 2. Learner promise & exit capability

统一入口：

> **你已经能完成工作，现在让这些工作产生曝光、线索与业务价值。**

Track 03 Exit Capability：

> 面对一个真实业务目标，学习者能够从已有研究、内容、数据和知识资产出发，明确目标受众与业务场景，设计可验证的内容与渠道动作，承接并判断线索，推进销售跟进与客服答复，用运营数据复盘结果，并识别哪些人工业务链已经稳定、值得进入 Track 04 系统化。

Track 03 不是「AI 写文案技巧合集」，也不是平台运营手册。能力链：

工作产物 → 业务定位 → 内容资产 → 渠道动作 → 线索 → 销售/客服推进 → 数据复盘 → 已验证业务链路

## 8. Cross-track boundary

### Track 03 owns
- ICP / Audience 的业务定位；
- Use Case / Problem-Situation；
- Value Proposition / Message Hierarchy；
- Content System / Distribution；
- Conversion / Lead / Qualification；
- Sales Follow-up / Objection；
- Customer Service response loop；
- Operations Metrics / Feedback Loop；
- 渠道方法层。

### Track 03 does not reteach
- Prompt / Context / Reliability / Search / RAG 基础；
- 普通写作、资料整理、文件比较、基础数据分析；
- “怎么让 AI 写得更好”这类 Track 01/02 已解决的问题。

### Track 04 owns later
Workflow decomposition / node design；Trigger / State / Stop / Failure；Retry / Timeout / Idempotency / Compensation；Automation；Code / Skill / Tool / Workflow / Agent responsibility architecture；API / MCP integration；Approval / HITL architecture；Workflow Evaluation / Regression。

Track 03 只要求人工业务链可执行、可检查、可复盘；不把它自动化。

### Track 05 owns later
Problem Discovery；Stakeholder / Current State / Target State；Value Hypothesis / Business Case；Solution Design / Build vs Buy；Prototype / Pilot；Evaluation / Adoption / Rollout。

## 9. Deferred / supporting resolution

公众号、视频号、小红书、抖音、B站、网站、企业微信、飞书、CRM 等变化快的平台只作为案例或独立 Channel Practice。Core Lesson 只教稳定业务方法，不把当前平台 UI 或按钮路径写成 Primary Knowledge Home。
