# FIVE_TRACK_CAPABILITY_CONTINUITY_V1.md — 五板块能力连续性

Status: **CURRENT / FROZEN**

本文件只说明五大板块之间“能力如何继续生长”，不维护单课文案、Batch、Formal Brief 或生产状态。

## 1. 总连续性

```text
AI Foundation
基础协作与机制判断
↓
AI Work
把 AI 稳定用进真实工作
↓
AI Growth
把 AI 用进内容、客户、运营与增长
↓
AI Workflow
把重复工作沉淀成可验证流程
↓
FDE
把能力组合成可交付的真实解决方案
```

## 2. Track 01 → Track 02

Foundation 提供：
- 任务边界；
- Prompt / Context；
- 结果核验；
- 模型 / 知识 / Search / RAG；
- API / Tool / MCP / Agent 等基础直觉。

AI Work 不重复教授这些概念，而把它们用于真实工作任务。

## 3. Track 02 → Track 03

AI Work 提供：
- 文档与资料处理；
- 信息转行动；
- 数据与判断基础；
- 工作输出质量控制。

AI Growth 将这些能力应用到内容、获客、销售、服务与运营。

## 4. Track 03 → Track 04

AI Growth 形成大量重复任务和跨步骤协作需求。

AI Workflow 进一步解决：
- 步骤拆分；
- 输入 / 输出契约；
- 人工 Gate；
- 状态与失败处理；
- 可复用自动化。

## 5. Track 04 → Track 05

AI Workflow 提供系统化执行能力。

FDE 不再以“做一个 Workflow”为目标，而是：
- 判断真实问题；
- 明确价值；
- 设计方案；
- 做最小试点；
- 收集证据；
- 推动采用；
- 完成交付。

## 6. Anti-overlap

切换 Track 的原则：

> Track switch = Context switch, not Workflow fork and not Skill fork.

后一板块必须新增能力，不得只换案例重复前一板块 Primary Knowledge Home。

如果未来重开课程生产，Formal Brief 必须明确：
- prerequisite；
- new judgment；
- anti-overlap；
- next capability value。
