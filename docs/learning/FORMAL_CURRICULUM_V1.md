# FORMAL_CURRICULUM_V1.md — OPC AI 正式课程体系

Status: **CURRENT / FROZEN CURRICULUM**

本文件只定义五大板块的长期课程结构与能力目标。81 节具体课程目录统一见 `TRACK_CONTEXTS_V1.md`，正式代码事实源为 `lib/learning/track-catalog.ts`。

## 1. 五大板块

### 01 AI Foundation — AI 基础认知
目标：理解 AI 的基本能力、限制、模型机制、知识、工具和现代 AI 基础概念，并能稳定与 AI 协作。

当前：20 节 / 6 阶段 / ALL AVAILABLE。

### 02 AI Work — AI 工作应用
目标：把 AI 用进文档、资料、分析、信息处理、判断和日常工作任务。

当前：15 节 / ALL AVAILABLE。

### 03 AI Growth — AI 增长
目标：把 AI 用进内容、获客、销售、服务、运营和增长复盘。

当前：15 节 / ALL AVAILABLE。

### 04 AI Workflow — AI 工作流
目标：理解并设计稳定、可验证、有人类边界的 AI 工作流。

当前：15 节 / ALL AVAILABLE。

### 05 FDE — 解决方案落地
目标：从真实问题出发，定义价值、设计方案、验证试点、用证据推进采用并完成交付。

当前：16 节 / ALL AVAILABLE。

## 2. 当前冻结状态

Track 01～05 共 81 节课程已经正式上线并冻结。

没有产品负责人显式重新开启：
- 不新增目录；
- 不合并 / 拆分课程；
- 不更改 Primary Knowledge Home；
- 不进入新的 Batch / Formal Brief；
- 不重新规划阶段结构。

## 3. Curriculum 决策原则

未来如果需要新增知识：
1. 先判断是否属于现有课程补充、Supporting Knowledge 或全新 Primary Knowledge Home；
2. 先做跨 Track anti-overlap；
3. 明确是否真的需要改变当前冻结 Curriculum；
4. 只有显式 Curriculum Decision 后才进入 Formal Brief。

不得因为 AI 热点、工具更新或单一案例变化直接修改正式课程目录。

## 4. Lesson Type

Lesson Type 只影响实践深度与 Completion Gate，不改变统一六步教学责任。

常见类型：
- CONCEPT
- APPLICATION
- PRACTICE / PROJECT（按当前 Runtime 支持范围）

具体类型和 Gate 以正式 LessonSpec 为准。
