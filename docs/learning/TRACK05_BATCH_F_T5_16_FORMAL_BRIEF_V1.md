## T5-16 — 把一个真实业务问题交付成完整 AI 解决方案
Lesson Role: **CAPSTONE INTEGRATION**
Core judgment: 真正的 FDE 交付不是一份漂亮方案，而是一条可追溯的决策链：为什么是这个问题、谁受影响、当前基线是什么、目标与价值是什么、为什么选这条解决路径、落地条件如何、如何验证、证据支持什么决定、谁长期负责。

Must-retain integration:
- Problem Observation + Stakeholder Map + Baseline；
- Problem / Target / Value Brief；
- Solution Option + Readiness + Scope；
- Prototype Hypothesis + Pilot Plan + Learning；
- Evaluation Decision + Adoption + Rollout Ownership；
- 所有未知、风险和待确认事项继续显式保留。

Practice: 学员选择一个自己的真实业务问题，把前面产物压缩整合成 **FDE Solution Package**。字段围绕“业务问题与事实、目标与价值、选择的解决路径、第一阶段范围、验证证据、继续/调整/停止决定、采用与长期责任、仍未解决的风险、希望 AI 帮我检查整个决策链什么”。

COPY_TO_AI: AI 只做完整性检查、矛盾检查、证据缺口检查和表达优化，不替学员补造事实、批准方案或决定组织责任。

Step 6 capability: 学员能把一个真实业务问题从发现推进到可交付、可复核、可继续迭代的 AI Solution Package。
