## Decision

Current six-step teaching rules are now used not only to build lesson pages, but to audit whether a knowledge point deserves to become an independent formal lesson.

Next main curriculum task:

**CURRICULUM-SIX-STEP-AUDIT-001 — Five-Track Core Curriculum & Knowledge Point Audit**

Before continuing large-scale lesson production, the five long-term tracks must be re-audited from capability outcomes backwards:

Capability Map → Knowledge Map → Course Directory.

Each candidate knowledge point must be evaluated as:

- KEEP — independent core lesson
- MERGE — merge into another lesson
- SPLIT — too broad, split
- SUPPORTING_KNOWLEDGE — necessary but not an independent lesson
- DEFER — move to advanced/elective
- REMOVE — insufficient value to the capability chain

## Six-step audit test

Every candidate Primary Knowledge Point must prove:

1. Why it matters in a real task.
2. What distinct core rule/method it owns.
3. How understanding can be tested by judgment.
4. What minimum learner action/result can be produced.
5. Which 2–4 reusable judgments remain after the lesson.
6. What new executable capability the learner gains and where it is reused next.

If a candidate cannot naturally pass this test, it should not be forced into a standalone lesson.
