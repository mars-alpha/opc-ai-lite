# MVP-008 — Interactive Lesson / Practice 最小学习闭环

Status: COMPLETE

## Goal

用一节现有 Lesson 验证 OPC 从“内容阅读”进入“理解检查 → 跟做 → 提交 → 检查 → 反馈 → 修改 → PASSED”的最小学习闭环。

试点：`Stage 2 / chatgpt-worker / task-brief`

## Stage A — Domain / Data Foundation

新增正式模型：`lesson_checks`、`lesson_check_responses`、`practices`、`practice_submissions`、`practice_evaluations`。

Migration：`drizzle/0003_bored_millenium_guard.sql`。

Submission 第一版仅支持结构化文本 / JSONB；不支持文件、图片、URL、视频、外部工具结果抓取。

## Stage B — Interactive Lesson UI / API

新增 `InteractiveLessonPanel`，以及：
- `GET /api/learning/interactive`
- `POST /api/learning/checks/[checkId]/answer`
- `POST /api/learning/practices/[practiceId]/submissions`
- `POST /api/learning/submissions/[submissionId]/evaluate`

试点支持 SINGLE_CHOICE 理解检查、五段 Guided Practice、静态 Hint、结构化文本 Submission，以及“复制到我的 AI 工具”。

## Stage C — Evaluation / Retry / PASSED

当前真实 evaluator = deterministic RULE。没有接入真实 AI Provider，不伪造 AI Evaluation。

反馈固定返回 score / reason / problem / suggestion / example / nextAction。

PASSED = total score >= passScore，且每个 required criterion >= minScore。

Submission 先持久化；Evaluation 失败时保留 Submission，并标记 EVALUATION_FAILED，可重新检查。

required Practice 未 PASSED 时，Backend 拒绝 Lesson COMPLETED。

## Known MVP boundaries

- 只对 `chatgpt-worker / task-brief` 开启 Interactive Lesson。
- 当前 Evaluation 是规则评价，不是语义 AI 评价。
- 不做综合 AI 能力总分、通用 AI Tutor / Chat、大型题库或考试系统。
- 不做文件、多媒体、URL Submission。
- 不做外部 AI 工具调用与结果抓取。
- 不做 MVP-009 Event / Analytics。
- 不做支付与新渠道。
