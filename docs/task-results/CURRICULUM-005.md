## New beginner path

Stage 1：先认识 AI 怎么用
1. AI 到底能帮我做什么
2. 为什么同一个 AI，有时好用、有时不好用
3. AI 为什么会说错，而且还说得很像真的
4. AI 软件里的模型、搜索、文件和记忆是什么关系

Stage 2：学会和 AI 基本协作
5. Prompt：怎样把想做的事情说清楚
6. Context：AI 只知道你这次给它看到的东西
7. 第一次结果不对，怎样继续让 AI 改好
8. AI 的结果什么时候能直接用，什么时候一定要检查

Stage 3 再补 Model / Training-Inference / Token / Context Window 等内部机制。
