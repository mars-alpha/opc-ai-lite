# COURSE-GOV-SIX-STEP-001 — Mandatory Six-step Rule for All New Courses

Status: **COMPLETE_GOVERNANCE_BASELINE**

## Decision

All new formal OPC courses now use the same mandatory six-step instructional contract:

EXPLAIN → EXAMPLE → CHECK → PRACTICE → REVIEW → CAPABILITY.

This applies across all five long-term tracks and all Lesson Types.

Every new Primary Knowledge Point must pass the six-step knowledge-point test before Course Builder production. If the knowledge point cannot naturally support all six steps, it must be merged, split, downgraded to supporting knowledge, or returned for curriculum redesign instead of forcing content into the shell.

Lesson Type changes Step 4 depth and Completion Gate only; it does not remove any of the six steps.

Advanced courses may use richer media such as diagrams, code, screenshots, labs or projects, but still pass the same six-step test.

## Governance impact

- Six-step is now a curriculum / production gate, not only a Beginner UI pattern.
- Formal Brief must describe the six-step teaching responsibility for each Primary Knowledge Point.
- Course Builder may not fabricate missing teaching logic just to fill six slots.
- Human Review continues to validate every step for clarity and content integrity.
- Continuity and Six-step are independent mandatory axes: one checks vertical course continuity, the other checks internal lesson teaching completeness.

## Additional cleanup

Aligned Beginner Cognitive Load Budget from old Step 5 max 3 rule to current 2–4 review framework rule.
