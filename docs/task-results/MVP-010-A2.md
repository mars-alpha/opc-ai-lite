# MVP-010-A2 — Practice Access Resolver

Status: COMPLETE

## Goal

把 A1 新增的 Practice type / ownership / access_tier 真正接入统一服务端权限解析，避免 Lesson Practice、Stage Project、Latest Practice 各自实现一套访问逻辑。

## New canonical resolver

新增：

```text
lib/server/practices/access.ts
```

核心入口：

```text
resolvePracticeAccess(userId, practiceId)
```

统一返回：

```text
allowed
reason
practiceId
type
accessTier
lessonId
stageId
sourceContentId
sourceKnowledgeId
requiredCourseSlug?
```

## Ownership validation

### LESSON_PRACTICE

必须存在：

```text
lesson_id
lesson slug
所属 stage / course
```

否则：

```text
PRACTICE_OWNERSHIP_INVALID
```

访问继续复用正式 `getLessonAccess()`，因此保留：

```text
Stage prerequisite
Public / free Lesson
公众号 Chapter Entitlement
OPC Membership
```

### STAGE_PROJECT

必须存在：

```text
stage_id
```

访问复用：

```text
getStageAccess()
```

因此 Stage Project 不会绕过学习路径前置阶段。

### LATEST_PRACTICE

必须至少存在：

```text
source_content_id
OR
source_knowledge_id
```

且至少一个真实 Source 必须：

```text
status = PUBLISHED
```

否则返回：

```text
PRACTICE_OWNERSHIP_INVALID
SOURCE_NOT_PUBLISHED
```

## Access Tier

正式解析：

```text
INHERIT
→ 使用所属 Lesson / Stage / Source 的基础访问规则

FREE
→ 基础业务前置条件满足后允许

MEMBER
→ 基础业务前置条件满足
  AND active OPC Membership
```

会员判断没有在 Practice 层重复实现，而是复用：

```text
resolveMembershipFeatureAccess()
```

Feature：

```text
STAGE_PROJECT → STAGE_PROJECT
其它 Practice → PRACTICE
```

## Existing submission flow integration

原 `getPracticeForUser()` 已改成先调用：

```text
resolvePracticeAccess()
```

统一映射：

```text
MEMBERSHIP_REQUIRED
STAGE_PREREQUISITE_REQUIRED
LESSON_LOCKED
PRACTICE_SOURCE_NOT_PUBLISHED
PRACTICE_OWNERSHIP_INVALID
```

Submission API 已同步 HTTP 状态：

```text
401 UNAUTHENTICATED
400 INVALID_PRACTICE_CONTENT
403 access denied
404 PRACTICE_NOT_FOUND
409 ownership / source state conflict
```

Interactive Lesson 只读取：

```text
LESSON_PRACTICE
```

避免 Stage Project / Latest Practice 因 lesson_id 偶然存在而进入 Lesson UI。

## Runtime validation

使用真实数据库临时样本验证后全部清理：

```text
LESSON_PRACTICE + FREE + public lesson     → ALLOWED
STAGE_PROJECT + FREE + first stage         → ALLOWED
LATEST_PRACTICE + FREE + published source → ALLOWED
LATEST_PRACTICE + MEMBER + no membership  → MEMBERSHIP_REQUIRED
STAGE_PROJECT without stage_id            → PRACTICE_OWNERSHIP_INVALID
```
