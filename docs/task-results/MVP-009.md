# MVP-009 — Feedback / Event 最小数据闭环

Status: COMPLETE_WITH_EXTERNAL_RUNTIME_PENDING

## Goal

建立 OPC 从真实学习行为与用户反馈出发的最小数据闭环：

```text
Event / Feedback
→ Rule Aggregation
→ Course Insight
→ AI Analysis（条件满足且 Provider 可用时）
→ Course Update Candidate
→ Human Review
```

不建设通用 Analytics 平台，不允许前端伪造服务端结果，不允许 AI 自动覆盖 Published 课程。

## Stage A — Data Foundation

新增正式模型：

```text
learning_events
learning_feedback
course_insights
course_update_candidates
```

Migration：`drizzle/0004_dapper_night_thrasher.sql`。

Course Insight 使用 `lesson_id + issue_key` 唯一聚合；Feedback 使用独立用户数作为阈值依据。

## Stage B — Event Trust Boundary

Learning Event API 只接受允许的低风险事件。

Practice / Evaluation / Lesson Completion 等正式结果事件由服务端业务逻辑写入。

Runtime 已验证：

```text
合法低风险 Event              201
前端伪造 practice_passed      400
```

因此 Event 不能被用户直接当成“完成证明”。

## Stage C — Feedback / Insight Aggregation

当前规则：

```text
0–2 位独立用户        OPEN
3+ 位独立用户         ANALYSIS_READY
5+ 位独立用户         HIGH priority
quality risk          REVIEW_REQUIRED / HIGH priority
```

已有课程可以回答的问题，直接返回课程入口，不调用 AI。

Runtime 已验证：

```text
已有课程问题 → 返回课程入口且不调用 AI      PASS
3 个独立用户同类反馈 → ANALYSIS_READY       PASS
单个“内容可能过时”反馈 → REVIEW_REQUIRED    PASS
```

## Stage D — AI Analysis / Candidate Boundary

代码链路已经接通：

```text
ANALYSIS_READY
→ runAiAnalysis()
→ Course Coverage Check
→ Course Update Candidate
→ PENDING_REVIEW
```

AI 输出只能形成结构化 Diagnosis / Proposal，不能直接修改 Published Lesson。

当前开发环境没有配置：

```text
OPC_AI_ANALYSIS_BASE_URL
OPC_AI_ANALYSIS_API_KEY
OPC_AI_ANALYSIS_MODEL
```

因此本轮没有真实 Provider Runtime Validation。

规则聚合没有被冒充成 AI 分析；当前达到条件后的真实状态仍是 `ANALYSIS_READY`。Provider 缺失或调用失败时保持该状态并记录错误。

独立后续项：

```text
MVP-009-AI-RUNTIME
Status: PENDING_EXTERNAL_CONFIG
```

该项不阻塞 MVP-010。

## Stage E — Admin / Human Review

Admin Learning Workbench 可以查看：

- Insight status
- analysis mode
- distinct user count
- evidence
- AI diagnosis（仅存在真实 diagnosis 时）
- Course Update Candidate

Candidate 默认 `PENDING_REVIEW`，人工可以批准为更新任务或要求重新分析。

## Known MVP boundaries

- 当前没有真实 AI Provider Runtime 证据。
- 不建设大型 BI / 通用埋点平台。
- 不做用户能力总分。

- 不允许 AI 自动修改 / 发布课程。
