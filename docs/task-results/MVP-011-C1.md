# MVP-011-C1 — Knowledge → Latest Practice Bridge

Status: COMPLETE

## Goal

建立正式的：

```text
Published Knowledge
→ Human-confirmed Latest Practice
→ Published Practice
→ Frontend discovery
→ Submission / Evaluation
```

本阶段不进入 Course Update Candidate、自动采集、自动改课或新的会员规则。

## Existing model reused

没有新增 Practice 表，也没有新增第二套 Submission 模型。

继续复用：

```text
knowledge_items
practices
practice_submissions
practice_evaluations
```

Practice 类型：

```text
LATEST_PRACTICE
```

正式 ownership：

```text
sourceKnowledgeId
sourceContentId
stageId
lessonId
```

## Admin routing

新增：

```text
GET  /api/admin/knowledge/items/:itemId/practice
POST /api/admin/knowledge/items/:itemId/practice
PUT  /api/admin/knowledge/items/:itemId/practice
```

在 `/admin/content` 的 Content → Knowledge 区域中，已有 Knowledge 后会继续显示：

```text
Knowledge → Latest Practice
```

管理员可以人工确认：

```text
title
goal
instructions
hints
rubric
submissionSchema
passScore
accessTier
status
```

当前正式 Submission Schema 仍只支持：

```text
TASK_BRIEF_V1
```

没有在本任务扩展新 Schema。

## Inheritance

Practice 从 Knowledge 固定继承：

```text
sourceKnowledgeId
sourceContentId
stageId
lessonId
```

这些 ownership 字段不由前端任意覆盖。

## Duplicate protection

同一 Knowledge 只允许一个 `LATEST_PRACTICE` 业务关联。

创建前按：

```text
type = LATEST_PRACTICE
AND sourceKnowledgeId = current knowledge
```

查找。若已存在：

```text
created = false
→ 返回已有 Practice
→ 不重复创建
```

当前仍是应用层幂等保护，没有新增数据库唯一约束，因此没有 Schema Migration。

## Publish boundary

允许未发布 Knowledge 先准备 Practice DRAFT / REVIEW。

但：

```text
Knowledge.status != PUBLISHED
AND Practice.status = PUBLISHED
→ KNOWLEDGE_NOT_PUBLISHED
```

因此不会出现“来源 Knowledge 未发布、Latest Practice 已对用户可用”的状态。

## Frontend reader

正式主数据源：

```text
knowledge_items.status = PUBLISHED
validity != OUTDATED / DEPRECATED
↓
optional published LATEST_PRACTICE
↓
/practice
/practice/latest
/practice/latest/[id]
```

`lib/contentDemo.ts` 只保留为数据库不可用 / 无正式数据时的开发 fallback，不再是上述页面的主业务读取源。

## Frontend behavior

`/practice`、`/practice/latest`、`/practice/latest/[id]` 已改为正式 Reader。

详情页规则：

```text
有 Course → 查看课程
有 Published LATEST_PRACTICE → 开始实操 → PracticeSubmissionPanel → Submission / Evaluation
无 Course / Practice → 独立 Knowledge 文稿
```

卡片仍遵守 UI-IA-001：不把 Submission UI 直接塞回列表卡片。

## Cache

Knowledge 创建 / 更新与 Latest Practice 创建 / 更新都会失效 `opc-latest-practice`。

正式 Reader：

```text
revalidate: 60
tag: opc-latest-practice
```

三个 Practice 页面当前为 dynamic server routes，新内容不需要重新 build 才能被发现。

## Validation

```text
npm run typecheck   PASS
npm run build       PASS
```

Production build 已生成 `/api/admin/knowledge/items/[itemId]/practice`，并确认 `/practice`、`/practice/latest`、`/practice/latest/[id]` 为动态路由。
