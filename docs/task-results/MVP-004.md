# MVP-004 — User / Auth 最小闭环

## Goal

把 MVP-003 的 Demo User 替换为真实 User + Session，使“加入学习（注册）→ Enrollment → Continue Learning → Progress”成为真实用户闭环。

## Architecture Decision

本阶段采用 OPC 自有最小 Auth，不使用 Supabase Auth。

原因：

- 核心 User 不绑定开发数据库供应商；
- 后续微信公众号 / 小程序可以继续通过 UserIdentity 接入；
- 保持 PostgreSQL 可迁移；
- 当前需求只需要可靠的注册、登录、Session；
- 不提前引入大型 Auth 平台或复杂 OAuth 框架。

## Schema


密码凭据与 UserIdentity 分离。

## Password Security

使用 Node.js 内置 `crypto.scrypt`：

- 每个用户独立随机 salt；
- 保存 password hash + salt；
- 登录校验使用 timingSafeEqual；
- 不保存明文密码。

## Session

Session Token：

- 32-byte cryptographically random token；
- 浏览器保存 raw token 于 HttpOnly Cookie；
- 数据库只保存 SHA-256 token hash；
- SameSite=Lax；
- Production 环境 Secure；
- 默认有效期 30 天。

## UI Flow

```text

↓

↓
创建 Session
↓
自动加入目标课程
↓
返回目标 Lesson
↓
继续学习
```

新增：

```text

```

支持：

- 注册 / 登录切换；
- email + password；
- 注册可选称呼；
- courseSlug；
- returnTo；
- 注册/登录成功后自动 Enrollment；
- 安全限制 returnTo 只能是本站相对路径。

Header：

- 未登录显示“登录”；
- 已登录显示“退出”；
- 主 CTA 保持“加入学习 / 继续学习”。
